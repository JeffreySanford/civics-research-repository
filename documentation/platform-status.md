## Product position

Civics Research Repository is an independent reference implementation of a federal Open Science repository and discovery platform. DSpace is the repository system of record; an application-owned discovery index powers public search; Angular and MapLibre provide an accessible discovery, research-object, workflow, and geospatial experience.

The platform is not affiliated with, endorsed by, or sponsored by the U.S. Census Bureau, USGS, DSpace, or Apache Solr.

## Discovery and synchronization

- DSpace owns repository items, metadata, relationships, access statements, versions, and bitstreams.
- The `DiscoveryIndex` boundary owns a rebuildable public projection; Apache Solr is the current implementation.
- Fourteen registered Spring adapters reconcile catalog-backed `ResearchObjectMetadata` into DSpace. Startup and admin sync use the same orchestration path.
- Publisher checks provide reachable file facts and vintage verification, while the catalog remains a curated declaration of which research objects belong in this reference repository.
- Fixture content is a labelled recovery path, never an undisclosed substitute for repository content.
