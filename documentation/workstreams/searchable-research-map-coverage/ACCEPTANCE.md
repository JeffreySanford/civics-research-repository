# Acceptance Criteria

- Discovery criteria can be represented consistently for spatial requests.
- Spatial summary endpoints are bounded and projection-aware.
- Explicit feature endpoints require bounds/detail controls and server-enforced caps.
- Research Coverage appears as its own expandable Maps category.
- Administrative summaries and explicit footprints remain separate child layers.
- Every mapped value has an equivalent semantic list/table representation.
- Map-originated selection has a matching semantic target and announcement path.
- No task depends only on canvas pointer interaction or dragging.
- Associated result lists reuse opaque cursor semantics for deep traversal.
- Browser evidence covers MapLibre visibility, disclosure controls, keyboard behavior, reflow, forced colors and WCAG 2.2-oriented checks.
